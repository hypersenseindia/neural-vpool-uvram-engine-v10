# Neural vPool / uVRAM Engine &mdash; v10

The previous build of the frame-pacing engine. Kept for reference &mdash; **use [v11](https://github.com/hypersenseindia/neural-vpool-uvram-engine-v11)** for new installs.

## What it is

A non-root Termux engine focused on frame-time consistency for 60&ndash;144 Hz panels, with a virtual memory pool and thermal-aware stepping.

## Run

```bash
pkg install -y git
git clone https://github.com/hypersenseindia/neural-vpool-uvram-engine-v10
cd neural-vpool-uvram-engine-v10
chmod +x *.sh
./engine.sh
```

## Status

Unmaintained. Bug reports and changes go to v11.

## Note

Tuning reduces stutter and background load. It does not add hardware performance.
